## Current projection

Make the map's operational route visible first. Preserve meaningful behavior and causal sources; remove repeated status and procedure where they create competing maintained facts. Let authorized implementation and feedback refine the map without requiring a complete initial design or a LOG/STATE/LOCK transaction for every repair.

Record target conditions that change action, actual installation entry points, shared contributions and consumers, removal requirements and evidence limits. Distinguish a user effect from a historical implementation choice. Retain existing authorized effects, clean-reconstruction policy and protocol identity. No accepted protocol bundle is rewritten, no new protocol format is adopted, and no installation, migration or cold-session learning success follows merely from completing this documentation.
