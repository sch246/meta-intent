## Attributable judgment

The virtue of the installation-map concept is extreme executability, and that same property supplies its optimization procedure: analyse how easily the map can actually be executed, and improve it where execution is hard. Executability is therefore not only what the map is for; it is the gradient along which the map is improved.

## Retained hypothesis, not adopted

The user asks whether development, under the installation-package metaphor, has the installation map as its compile target. This is recorded as an open question in the user's own words. It is not current authority, and nothing in STATE presently depends on it.

The hypothesis is retained because it may organize how the map is optimized, not because it has been shown to hold.
