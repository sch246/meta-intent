## What meta-intent already carries

Most of the epistemic core has already been independently expressed in current meta-intent STATE or selected source records:

- finite current projection over growing provenance;
- distinct authority for source history, current meaning and realized facts;
- query-driven reading rather than a mandatory permanent graph;
- inclusion, omission and lost attention as inspectable provenance rather than inferred truth;
- current STATE before historical detail, with full replay retained for audit;
- code and tests as reality evidence rather than semantic authority.

ContextOS therefore does not justify a fourth meta-intent authority area, a universal memory layer or a fixed semantic graph. It provides older source support and counterexamples for decisions already reached.

## Bounded new value

Two ContextOS criteria sharpen the existing cold-session experiment without yet changing STATE or protocol:

1. **Consumption criterion.** A derived summary, index or working set does not establish self-context management merely by existing. A later cognitive operation must actually consume it and receive a different working set. ContextOS states this explicitly in current `ARCHITECTURE.md` lines 25-31 and 191. For meta-intent, retrieval quality should therefore be observed through a downstream maintenance judgment, not only by asking whether an Agent can summarize the right history.
2. **Selection-accounting criterion.** The system should make inspectable why information was included, excluded or downgraded. This is compatible with replaceable navigation views and why-not provenance. It does not imply that every exclusion becomes permanent schema or current STATE.

These are experiment lenses. Neither has enough evidence to become a protocol invariant.

## Historical branches that remain non-authoritative

The following branches may explain later vocabulary but are not adopted meta-intent design:

- files as Context nodes, reference counting, copy-on-write, tracing GC, a nightly organizer or an index stored at the end of a main session;
- persistent workspace versus cognitive trajectory as the single carrying unit;
- Context Store, Context Compiler, Cognitive Scheduler, fixed cognitive stages or a universal Context record;
- Cordis as a distributed process protocol, NATS/KV as runtime truth, or a cross-device daemon;
- Factor as a unified declaration, dependency node, resource owner, generation boundary or capability entry;
- Effect v4, Scope/Fiber, reactive service-coordinate tracking, generation/HMR and resource-drain mechanisms;
- five-elements analogies as a type system or architectural proof.

Several of these are explicitly unresolved or rejected inside current ContextOS itself. Factor and Effect probes show bounded implementation behavior but do not establish the ContextOS ontology, and they have no demonstrated need in meta-intent.

## Preserved conflict

Current ContextOS retains an unresolved conflict between its broad goal—an Agent that self-manages a Context System—and the earlier direct user claim that the purpose is only context purity and that Context System and LLM are different layers. Meta-intent has a narrower package-maintenance purpose and must not resolve that ContextOS-local conflict by absorbing either side.

Likewise, persistent workspace and trajectory-branch models remain competitors. Their existence supports testing retrieval under different questions; it does not authorize selecting one as the shape of LOG or STATE.

## Next falsifiable experiment

The next qualifying cold-session experiment should begin with only the repository bootstrap entry and current STATE, with read-only repository access and no prescribed source files. Each cold Agent receives a concrete maintenance question. It must report what it retrieved, what it deliberately did not retrieve, inaccessible scope and uncertainty. Its retrieved working set must then be consumed in a downstream recommendation or candidate review.

A full-history reader answers the same question as a comparison. The evidence is the difference in downstream judgment, recovered causal chain, uncovered omissions, context cost and ability to identify unknown scope. A summary that sounds correct but is not consumed does not pass. This audit itself is not that experiment because its source allocation was prescribed in advance.

Candidate questions should exercise different failure modes: whether to add a fixed semantic index, whether implementation evidence can revise intent, and whether an old Factor/Effect probe creates a present dependency. No persistent retrieval structure is warranted until observed omissions require one.
